# 🌦️ Nimbus Ridge Weather Bulletin Service

> **How do LLM generation parameters affect the quality of AI-generated weather bulletins?**

A systematic experiment that studies how **temperature**, **top-p**, **max tokens**, **stop sequences**, and **seed** influence the faithfulness, diversity, and structure of weather bulletins generated by an LLM for a fictional hill-station community.

---

## 📌 Overview

The **Nimbus Ridge Weather Bulletin Service** is a case study that uses an LLM (Groq's `allam-2-7b`) to convert structured weather readings into short, plain-language bulletins for villagers in hill districts. The project runs **400 API calls** across a controlled parameter grid and then evaluates every response for:

| Metric | What it measures |
|---|---|
| **Diversity** | Pairwise word-level edit dissimilarity across repeats |
| **Faithfulness** | Hallucinated sky conditions, wind directions, times, storms, etc. |
| **Truncation** | Whether the response was cut short by `max_tokens` |
| **Advisory completeness** | Whether the required `Advisory:` line is present |

### Key Findings

- **Temperature 0.0** produces deterministic, faithful outputs (0 % hallucination flags) but zero diversity.
- **Temperature ≥ 1.0** boosts creativity at the cost of reliability — non-English text appears in 20–32 % of responses, and invented storm warnings jump to 16 %.
- **top_p** has a milder effect than temperature; values ≤ 0.6 keep diversity low without spiking hallucinations.
- **max_tokens = 40** truncates 100 % of responses, losing the advisory line 56 % of the time.
- **seed = 42** locks outputs to identical text across all repeats (diversity = 0).

## 🚀 Quick Start

### Prerequisites

- Python 3.9+
- A free [Groq](https://console.groq.com/) API key (or any OpenAI-compatible endpoint)

### Installation

```bash
pip install openai pandas matplotlib
```

### Running the Experiments

```bash
# Set your API credentials
export API_KEY="your-groq-api-key"
export BASE_URL="https://api.groq.com/openai/v1"
export MODEL="allam-2-7b"

# Run the full experiment grid (400 calls, resumable)
python code/run_experiments.py --workers 2 --delay 2

# Quick smoke test (5 calls only)
python code/run_experiments.py --smoke
```

### Generating Analysis & Charts

```bash
# Diversity, length, and token-usage analysis
python code/analysis.py --input data/raw_log.csv --output results

# Faithfulness & truncation flag analysis
python -I code/review_flags.py data/raw_log.csv results
```

## 🛠️ Tech Stack

- **LLM**: [Groq](https://groq.com/) `allam-2-7b` via OpenAI-compatible API
- **Language**: Python 3
- **Libraries**: `openai`, `pandas`, `matplotlib`
- **Experiment Design**: One-variable-at-a-time grid with 5 weather inputs × 4–5 parameter values × 5 repeats

---

## 📈 Parameter Grid

| Parameter | Values Tested | Default |
|---|---|---|
| `temperature` | 0.0, 0.3, 0.7, 1.0, 1.4 | 0.7 |
| `top_p` | 0.3, 0.6, 0.9, 1.0 | 1.0 |
| `max_tokens` | 40, 80, 160 | 200 |
| `stop` | `\n\n`, `Advisory:` | None |
| `seed` | 42, off | None |

Each setting is tested across **5 weather inputs** with **5 repeats** each, holding all other parameters at their defaults.
